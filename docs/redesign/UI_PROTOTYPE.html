精简版 · 原型说明

设计规格与可操作的评审路径 / v1.0 · 2026-09-19

这是独立交互原型。所有人物和记录均为虚构，模拟分类、手动导入及检索；不会调用模型、读取所选文件内容或保存数据。刷新即重置。
01 / 试一次保存

新建记录，切换“相关／普通日常／待确认／失败”。普通日常不能强制入库。

02 / 补充一份报告

打开“项目奖金迟迟未结清”，补充地点，重新分析后仍保留你的修改。

03 / 用媒体找回来

搜索里选择图片、音频或视频，再使用演示素材，可跳转到命中片段。

04 / 看导入过程

设置 → Day One → 模拟导入 JSON ZIP。批次中展示收录、跳过、待确认及失败。
