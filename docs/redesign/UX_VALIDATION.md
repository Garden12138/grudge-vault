# 用户体验优化验证记录

2026-10-03；运行环境为 macOS、Node 24.10.0、pnpm 11.23.0。风格为清爽温和，主导航保持时间线、搜索、设置。

## 实现范围

| 区域 | 已实现的行为 | 主要验证方式 |
| --- | --- | --- |
| 首次记录／连接 | 只读预检查，同一弹窗配置；读取失败可重试，连接失败保留全文及附件，连接成功不自动提交 | `record-setup.spec.ts` |
| 筛选与待确认 | 判断并收录；跳过不入库；当前待确认 inline，用返回的 pendingId 确认或重新筛选；忽略清空；全局抽屉继续处理其他项目 | `use-record-intake.test.ts`、核心 Electron 流程 |
| 输入生命周期 | 锁定、工作区切换、关闭释放处理会话；迟到准备／筛选结果不能恢复旧界面；重复操作串行 | intake hook、workspace fail-closed、锁定 E2E |
| 报告 | 摘要与字段／下一步优先；字段旁编辑；补充保存使报告待更新，不自动调用；修订保护、用户字段与旧报告保留；折叠媒体及法律 | 时间编辑、修订、法律和原件 E2E |
| 搜索 | 提交前只读索引状态，真正可用时默认语义；未知／未配置先本地关键词；筛选折叠和可移除标签；实际结果决定降级与分页 | 冷索引取消、核心搜索、responsive E2E |
| 空库 | 独立 `timeline({limit: 1})`，读取失败不显示空库，筛选无结果保留条件 | timeline state 单测与 E2E |
| 设置 | 模型服务／导入／隐私与安全页内分组，共享连接表单，高级字段保留；推荐不等于验证，主导航重新进入回到模型组 | 设置读失败、模型配置、导入恢复 E2E |
| 视觉与键盘 | SVG 图标，正文 15px、帮助 13px、标签至少 12px、按钮至少 40px，固定编辑器底栏与焦点循环 | 1180／1024／840／390px 布局及键盘 E2E |
| 隐私边界 | 原件加密与 SQLite 本地正文／索引分别说明；模型外发、收费与服务商留存明确，未提交完整输入仅在内存 | 文案与现有生命周期回归 |

未增加公开 IPC、数据库字段或迁移。保留普通日常零逐条存储、搜索降级、旧报告、来源定位、导入暂停和失败恢复。

- 时间线显示最近导入的处理数量和批次状态。旧批次缺少摘要时明确说明覆盖范围未知，不从正式记录数量推断整包已经检查完成。
- 真实筛选捕获到来源锚点校验失败。给模型提供正文 Unicode 码点长度和范围上限，说明纯文字无需媒体编号、不确定的可选位置可以省略；唯一的一次格式修复提供问题字段及校验代码，不发送失败字段的原始值。保留来源和完整媒体覆盖校验，没有增加格式重试次数。
- Node 24／pnpm 11.23 下静态检查、类型检查、生产构建通过；相关单元与集成 176 项、模型协议 168 项通过。最终代码的 3 条相关 Electron 流程连续通过。DMG、ZIP、包内 SQLite／媒体组件及当前生产入口一致性验证通过，修复版已安装，原应用和工作区回退副本保留。

## 2026-10-06 密码与时间线优化

- 锁定页改为“欢迎回来／输入密码，继续查看你的记录”，隐私细节折叠。旧账本可以直接设置密码，也可以暂时打开；已设置密码的账本在锁定、重新选择文件夹及重启后都必须验证。设置页“隐私与安全”支持设置、修改密码及导出既有恢复包，密码由用户自行决定。
- 密码验证在主进程执行，使用随机盐与 scrypt 校验，不保存明文密码。连续错误会短暂限制重试；锁定、切换工作区和迟到请求不能重新打开旧会话。密码限制应用内访问，不将正文数据库整库加密；独立恢复包验证成功后可重新设置密码。此次新增密码 IPC 和可选配置字段，没有数据库迁移。
- 时间线改为一条连续线：日期、节点和简短描述常驻，完整卡片在鼠标悬停或键盘聚焦时显示。Escape 收起、Enter 打开，触控直接进入详情。日期型导入标题使用已有摘要展示简述，不改写原始标题或日期。保留来源待核对及分析失败等状态。
- 类别、来源及日期控件统一高度和基线；窄屏自动分两列。轻微背景动效遵循系统减少动态效果设置。1180、1024、840、390px 布局无横向溢出；返回详情前的筛选、分页和滚动位置保留。导入摘要在查看详情期间继续保留，避免返回时因重新载入摘要而发生位置跳动。
- Node 24.10.0、pnpm 11.23.0：lint、typecheck 和生产构建通过；全量单元与集成 70 个文件、1214 项通过，21 项沿用跳过。滚动位置修复后相关 Renderer 14 项复测通过。
- Electron E2E 全量 36 项中 33 项首先通过；两项旧锁定文案定位已更新，一项返回位置问题已修复，三项均复测通过。最终代码再次通过完整记录／报告／搜索、密码锁定与重启、时间线预览和四宽度布局、读取失败重试四项流程。一次受限沙箱启动失败未计为产品测试通过，随后在允许启动 Electron 的环境完成验证。

- DMG、ZIP、运行身份、图标、SQLite、原生媒体组件与当前生产构建一致性验证通过。真实生产安装包在隔离空账本中通过创建、设置密码、重启保持锁定及正确密码打开检查，没有 Renderer 错误或模型配置。
